# Парсер цен + дашборд

Мониторинг цен конкурентов: скрипт собирает цены в CSV с историей, дашборд строит графики динамики и сводку.

## Стек

- Node.js 18+ (встроенный `fetch`)
- cheerio — парсинг HTML
- Chart.js — графики

## Запуск

```bash
npm install
npm run parse    # собрать цены (дописывает строку в prices.csv)
npm run serve    # поднять дашборд → открой http://localhost:3000
```

## Как добавить свой сайт

В `parse.js` в массив `TARGETS` добавь объект:

```js
{ shop: "название", url: "https://...", selector: "css-селектор цены", product: "товар" }
```

Запускай по расписанию:
- Windows: Task Scheduler → `node parse.js` раз в сутки
- Linux/VPS: crontab `0 9 * * * cd /path && node parse.js`

## Демо-данные

Чтобы посмотреть дашборд без реальных сайтов, в файле `prices.csv` уже есть история за несколько дней.

## Важно

Парси только разрешённые к парсингу сайты: смотри `robots.txt` и условия использования. Для демо используй собственные страницы или API.
