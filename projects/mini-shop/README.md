# Мини-интернет-магазин

Каталог товаров с фильтрами по категориям, поиском, корзиной на localStorage и оформлением заказа. Без фреймворков и сборки.

## Возможности

- Фильтрация по категориям + живой поиск
- Корзина сохраняется в localStorage — переживает перезагрузку
- Изменение количества, подсчёт суммы в реальном времени
- Форма заказа с маской телефона и валидацией
- Товары вынесены в `data.js` — контент меняется без правки кода

## Запуск

Открой `index.html` в браузере или:

```bash
npx serve .
```

## Кастомизация

- Товары и категории: `data.js`
- Цвета: CSS-переменные в начале `style.css`
- Отправка заказа: см. комментарий в конце `script.js`

## Что можно добавить

- Реальный бэкенд (заказы в БД, админка)
- Оплату (ЮKassa, Robokassa)
- Страницы товаров с фото-галереей
