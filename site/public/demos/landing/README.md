# Лендинг барбершопа

Продающий одностраничник для локального бизнеса: hero, услуги с ценами, галерея, отзывы, форма записи с маской телефона.

## Технологии

Чистые HTML + CSS + JavaScript, без фреймворков и сборки. Никаких зависимостей — мгновенная загрузка.

## Запуск

Просто открой `index.html` в браузере. Или подними локальный сервер:

```bash
npx serve .
```

## Особенности

- Адаптив (mobile-first), sticky-хедер
- Анимация появления блоков на IntersectionObserver
- Маска телефона `+7 (___) ___-__-__` и валидация формы
- Учтён `prefers-reduced-motion`

## Кастомизация под клиента

- Цвета — CSS-переменные в начале `style.css`
- Тексты и цены — прямо в `index.html`
- Отправка формы — см. комментарий в конце `script.js`
