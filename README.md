# Портфолио вайбкодера

Витрина проектов для старта фриланс-карьеры.

## Структура

| Папка | Проект | Стек |
|---|---|---|
| `site/` | Сайт-портфолио | Next.js, Tailwind CSS |
| `projects/telegram-bot/` | Telegram-бот записи клиентов | Node.js, grammY |
| `projects/landing/` | Лендинг барбершопа | HTML, CSS, JS |
| `projects/parser-dashboard/` | Парсер цен + дашборд | Node.js, cheerio, Chart.js |
| `projects/mini-shop/` | Мини-интернет-магазин | HTML, CSS, JS |

## Быстрый старт

Каждый проект запускается отдельно — см. README внутри его папки.

## Публикация

- Сайт: деплой на Vercel (см. `site/README.md`)
- Бот: токен через @BotFather (см. `projects/telegram-bot/README.md`)
